GUIDE 기관 사이트 전체 파일

1. 실행
압축을 전부 해제하고 index.html을 브라우저에서 여세요.
역대 마법소녀 기록만 확인하려면 records.html을 여세요.
폴더 구조를 유지해야 이미지, 스타일, 스크립트가 정상적으로 표시됩니다.

2. 포함된 기능
- 기관 홈페이지와 공지, FAQ
- 상단 GUIDE 로고를 3초간 누르면 나타나는 관리자 인증
- 관리자 기밀 문서 보관소: 검색, 분류, 정렬, 열람 표시
- 기존 FAQ 네 개를 모두 펼치면 다섯 번째 질문과 기록 페이지 링크 등장
- 역대 마법소녀 15명: 사망 9명, 변질 6명
- 기록 페이지 진입 시 노이즈 연출 (건너뛰기 버튼 또는 Esc로 종료)
- 프로필 정보 패널은 처음에 닫혀 있으며 하단 화살표로 열고 닫음
- 시스템의 동작 줄이기 설정이 활성화되어 있으면 진입 연출 생략

3. 작품용 관리자 계정
직원 ID: AD-000
접근 코드: REDACTED07
계정 및 문서 수정: archive-data.js

4. 인물 사진과 프로필 수정
records-data.js에서 인물별 [이름 사진 교체 위치] 주석을 찾으세요.
해당 인물의 image에 외부 이미지 파일의 직접 HTTPS URL을 지정하세요.
예: image: 'https://your-domain.com/seo-yoon.gif'
GIF, WebP, PNG, JPG를 지원하며 자동 맞춤(contain)으로 표시합니다. 각 인물에 fit: 'cover'를 추가하면 영역을 채우도록 자릅니다.
세로형 이미지를 권장하며, 비어 있거나 경로가 잘못되면 실루엣을 표시합니다.
사망자 X 표시는 사진과 별도 레이어라 사진 교체 후에도 유지됩니다.
이름·기수·날짜·상태·변질 사유·현황도 같은 파일에서 수정합니다.

5. 수정 위치
index.html: 기관 홈페이지 내용, 숨겨진 FAQ 문구와 링크
app.js: 공지와 FAQ 기믹
style.css: 기관 홈페이지 디자인
archive-data.js: 관리자 계정과 기밀 문서
archive.js / archive.css: 관리자 화면과 동작
records.html: 역대 후보생 페이지 구성
records-data.js: 15명 프로필과 이미지 경로
records.js / records.css: 프로필 표시, 검색, 필터, 슬라이드
signal-entry.js: 진입 노이즈 연출 (duration은 밀리초)

6. 웹에 올리기
ZIP을 해제한 내용 전체를 같은 구조로 업로드하세요.
별도 빌드나 설치는 필요하지 않습니다.
직원 포털 링크는 기존 온라인 직원 포털로 연결됩니다.
이 ZIP에는 이전에 별도로 제공한 직원 포털 자체는 포함하지 않았습니다.
ChatGPT 사이트 호스팅의 로그인 제한은 ZIP에 포함되지 않습니다.
관리자 계정은 작품용 화면 전환이며 실제 서버 인증이 아닙니다.
코드와 기록은 소스에서 확인할 수 있습니다.

7. 외부 이미지와 GIF
site-media.js의 GUIDE_MEDIA에서 hero.url(기관 대표 이미지), administrator.url(관리자 본모습)을 수정합니다.
https://로 시작하는 이미지 파일의 직접 URL을 넣으세요. 공유/미리보기 페이지 URL은 이미지로 표시되지 않을 수 있습니다.
GIF와 animated WebP는 img 요소로 재생합니다. GIF 내부의 반복 횟수 설정을 따릅니다.
관리자 이미지가 비어 있거나 실패하면 동봉된 회색 실루엣으로 대체합니다.
대표 이미지 URL이 비어 있거나 실패하면 기존 기관 그래픽을 유지합니다.
관리자 GIF는 재생 길이와 관계없이 약 2.3초 후 차단 연출로 넘어갑니다.

8. 관리자 접속 이벤트
admin-event.js의 timing에서 시간을 조정합니다. 단위는 밀리초입니다.
로그인 성공 후 누적 1분(60000): 동일 계정 접속 시도 알림
누적 3분(180000): 계정 소유자 접속 알림
누적 5분(300000): 관리자 메시지
메시지 6.5초 후 본모습 이미지, 약 2.3초 뒤 화면 종료와 차단 문구
접속 종료 버튼을 누르면 타이머와 알림이 정리됩니다. 재로그인하면 처음부터 시작합니다.
탭을 옮겨도 경과 시간은 계속 흐릅니다. 숨겨진 탭에서는 이미지 등장 전까지 대기합니다.
차단은 해당 페이지 세션에 적용되는 극중 연출입니다. 새로고침하면 기관 홈페이지부터 다시 탐색할 수 있습니다.
페이지 전체 새로고침 시 타이머도 초기화됩니다. 실제 계정 접속/추적/통신은 없습니다.

9. 최종 기록실
기존 8건 + 통합 기록 9건, 총 17건. DIR-000을 시작으로 연관 문서로 이동할 수 있습니다.
기관의 실제 목적, 코스튬 안감 개체, 현 다섯 명, 블랙의 협조자 지정, 블루의 유보와 유출물 회수,
IN-001 제거와 IN-002 인계, 실패자 상태 구분, 외부 위탁 기록, 관리자·연구원 대화를 포함합니다.
RES-025 문서에서 역대 후보생 원장(records.html)을 새 탭으로 열 수 있습니다.
관리자 기록에는 기관이 모르는 외부 메시지 위치/기믹 조작법/블루 사본의 남은 위치를 적지 않았습니다.
게임 밖 해답 노트와 최종 진실 기록실의 역할을 구분했습니다.
융합 관찰 지표 68/54/41은 임시 설정이며 완성도·생존 확률이 아닙니다.
